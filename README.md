# Benchmark Quote Generation Tool

A multi-user web application that replaces manual Excel-based customer
quotations with a rule-driven quote and BOM generator for Benchmark
Broadcast Systems presales.

## Tech Stack
- Frontend: JavaScript (React)
- Backend: Python (FastAPI)
- Database: PostgreSQL
